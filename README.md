# Slip Kiosk - code repo

Asli code: `slip_bridge.py` aur `slip_kiosk_app.py` (is repo ki root mein).
Har commit par GitHub Actions inhe pack karke Pages par `data.txt` bana deta hai
(link kholne par koi file download nahi hoti, code bhi nahi dikhta).

Pages setting (ek dafa): Settings > Pages > Source = **GitHub Actions**.

Code badalna: .py file edit karein > Commit. Actions tab mein "Publish code to Pages" green hone ka intezar karein
(1-2 min). Exe agli dafa start hone par naya code le leta hai.
